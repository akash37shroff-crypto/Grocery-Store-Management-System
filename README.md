Grocery Store Management System

About

A simple Python-based grocery billing system that manages products, stock, and customer bills.

Features

- Add grocery items to cart.
- Calculate total bill.
- Apply 10% discount on bills of ₹1000 or more.
- Calculate 5% GST.
- Update available stock.
- Save bills in "bills.txt".

Technologies

- Python
- Lists and Dictionaries
- Functions and Loops
- File Handling

Products

- Rice – ₹50/kg
- Sugar – ₹45/kg
- Milk – ₹30/L
- Oil – ₹150/L

How to Run

python grocery_store.py
